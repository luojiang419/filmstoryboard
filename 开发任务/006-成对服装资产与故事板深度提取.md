## 任务目标

分析 N 人后仅自动创建 N 个模特格、N 个服装参考格、一个场景格；资产库可拖拽替换；上装、下装、套装按区域自然穿着，空槽保留，多人关系不串位。故事板右侧增加“画面提取”，深度结果可查看原图、双击对比，并自动提供给影视制作深度格。本机 D:\Program Files\filmstoryboard 自动升级，产品及安装版本一致。

## 技术方案

- 保留底层 product sortOrder / ID 以兼容旧绑定，仅规范准备资产领域结果和显示名称；旧识别结果在读取时规范化，不反复调用视觉模型。
- 共用换装规则覆盖上装、下装、连体/套装、平铺/人台/他人穿着图；动态编译每个人独立图片编号关系。场景图明确成为最终环境唯一来源，排除末尾旧环境约束。
- 使用现有 PersonDepthService 模型，复用故事板图片任务记录、结果归属检查和原图溯源。深度图为派生结果，影视制作继续用对应彩色/线稿源图；以原图内容指纹保存深度关联，避免把深度灰度图当生成底图。
- 不删除历史资产或用户数据；保留工作区原有无关未跟踪文档。

## 验收标准

1. 0/1/2/N 人返回 2N+1 个自动资产格，无鞋包等额外自动格。
2. 同编号服装归属对应人物，人物保留时也允许换装；场景引用实际进入请求且提示词无禁止背景冲突。
3. 深度提取按画板任务归属执行，切换画板或原图变化不会写错格；原图可追溯比较。
4. 深度关联持久化，进入准备资产可沿用，源图改变不误用旧深度。
5. 定向与整体检查通过，Windows Release 构建完成；安装 exe 和 Windows 安装记录版本同步。
