# Seedance 2.0 / 即梦参考图生视频提示词规则

规则依据软件内置的《Doubao Seedance 2.0 系列提示词指南》整理。本文件只服务参考图生视频提示词编写，不包含 LibTV 命令、画布操作或其他模型规则。

## 基础句式

使用 `@图片 N` 指定素材作用，例如：

```text
参考 @图片 1 中的主体，生成主体完成指定动作的视频。
```

多张图片必须说明各自角色。连续动作阶段图应声明为同一镜头的时间顺序参考，不把图片数量机械等同于镜头数量。

## 图生视频优先级

1. 素材引用与主体绑定。
2. 主体做什么，以及动作如何随时间推进。
3. 一种主要运镜及必要景别。
4. 用户明确要求的声音、风格和限制。

参考图已经表达的主体外观、服装产品、场景、空间关系、构图和光影不重复展开。不得猜测或重新指定服装、产品、材质、品牌和颜色；只有用户文字明确要求改变时才写具体属性。

## 复杂度规则

- 简单单镜头：使用简洁自然的一段话。
- 多张连续阶段图：静态主体和环境只定义一次，正文重点描述图片之间的动作路径。
- 用户明确要求多镜头：才使用按时间顺序的镜头结构；每个镜头写动作、运镜和必要声音。
- 一个镜头尽量只指定一种运镜，避免推拉摇移同时堆叠。
- 描述尽量简洁，避免冗余、语义冲突和与参考图不一致的空间文字。

不得输出 MiniMax H3 的六字段、`<Subject N>`、`<Picture N>`、`[Shot N]`、`retention_analysis` 或“参考生成”等标签。最终只返回可直接提交的中文提示词正文，不超过 1800 个字符。
