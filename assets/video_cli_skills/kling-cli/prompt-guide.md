# 可灵图生视频提示词规则

本文件只负责把已经上传的参考图编译成可灵图生视频提示词。不得套用 MiniMax H3、Seedance、文生视频或 CLI 操作规则。

## 核心原则

1. 参考图是主体外观、服装产品、场景、构图和光影的主要事实来源；文本主要描述接下来发生的动作和镜头运动。
2. 使用简洁自然的中文句子，避免复杂长句、文学化环境复述和关键词堆砌。
3. 不猜测、不重写参考图中服装、产品、材质或颜色；只有用户文字明确要求改变时才写具体属性。
4. 单一连续镜头只指定一种主要运镜。动作必须符合参考图姿态和物理规律。
5. 多张连续阶段图只说明图片顺序与阶段之间的动作路径，不逐张复述静态画面。
6. 提示词优先级：参考关系 → 主体动作链 → 单一运镜 → 必要约束。不得输出 H3 字段、`<Subject N>`、`[Shot N]` 或任务分析。

## 推荐结构

```text
图片1至图片N作为同一连续镜头的顺序动作参考。保持图片中的主体、场景和外观一致。主体从图片1的姿态自然完成……，连续过渡到图片N的姿态。镜头……，单一连续镜头，无切镜。
```

单张参考图时不必描述图片已有的静态细节，直接写“图片中的主体做什么、镜头怎么动”。最终提示词不超过 500 个字符。
