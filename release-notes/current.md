## 本次更新

- 一键复刻改为严格使用“原视频帧 + 当前镜头已绑定素材”：人物、产品、场景和道具只按各自镜头绑定提交，未绑定素材不再混入生成请求。
- 复刻分镜图锁定原视频帧的构图、镜头语言、色彩风格、色温与光影层次；新素材只替换对应视觉实体。
- 强化人物和产品替换：绑定人物时不再沿用原帧人物外观；产品保留真实结构、包装、纹理、材质与反光，并要求清晰可辨。
- 优化镜头资产绑定与自动匹配、脚本工作流恢复及图片生成 API 配置校验。
- 修复相关 Windows 资源缓存、界面折叠状态与图像生成稳定性问题。

> Windows 安装包当前未使用公共代码签名证书，部分设备可能显示 SmartScreen 提示。
