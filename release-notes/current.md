## 本次更新

- 修复本地 H3/MiniMax 视频 API 任务已生成完成但软件仍显示 `timedOut` 的问题；进入视频生成页后会后台继续查询历史超时任务，不会重新提交或重复扣费。
- 本地视频 API 查询会在任务接口未返回完成视频时继续读取 `/api/works` 作品库，命中同一 `generationId` 后自动下载并同步回对应分镜镜头。
- 修复当前工程生成视频列的显示路径解析；已完成视频无论保存为绝对路径还是工程相对路径，都能正确出现在“生成视频”列中。
- 合成提示词新增 H3 规则版，基于官方 H3 手册生成“参考素材说明 / 核心创意 / 画面过程描述 / 声音设计 / 非叙事性音乐”结构。
- 提示词版本入口统一为“可灵 / H3 / 即梦”，视频生成页为“可灵 / H3 / 即梦 / 手工稿”，方便直接对比不同模型规则。
- 视频生成页未生成视频时，生成视频格子内直接显示“生成视频”按钮，不再收纳到右下角圆形菜单。
- 可灵 3.0 Omni 图生视频提示词改为按官方 `图片1`、`图片2` 输入编号引用，普通首帧和首尾帧生成都能正确指向素材。
- 首尾帧动作组提示词改为镜头时序结构，保留中间动作过程，并明确从 `图片1` 自然过渡到 `图片2`。
- 视频生成提交前会读取可灵模型输入能力；当前模型不支持尾帧输入时会阻止首尾帧提交，避免无效扣费请求。
- “自动解析全部”会正确写回连续动作布尔字段，并对视频解析/拍摄脚本解析结果进行保守后处理，自动补齐首尾帧动作组端点。
- 首尾帧模式下，可灵提示词会保留中间动作过程；生成视频可只使用首帧和尾帧，中间帧作为动作描述写入提示词。
- 合成提示词默认选中并同步“可灵”，即梦规则版仍保留并可手动切换。
- 首尾帧模式下，“确认镜头”和“合成提示词”表格会显示首帧、尾帧、复刻首帧和复刻尾帧；一键复刻会为连续动作组生成首尾两张端点复刻图。
- “合成提示词”按钮文案改为基于已解析脚本字段合成，避免误以为会在此步骤重新调用视觉模型。
- 一键复刻分镜默认执行“纯净无字画面”硬约束：原视频帧及参考素材中的字幕、文字、数字、Logo、水印、商标、台标、角标、二维码和条形码均不得复制或重绘，并以自然无标识细节重建。
- 只有用户在单镜头“复刻补充说明”中明确给出需要逐字出现的具体文本时，才允许生成该段指定文本；参考图中的其他文字和 Logo 仍会被禁止。
- 视频生成工作区的“原视频、复刻分镜图、生成视频”三列统一显示镜头编号，标题基线和媒体顶部水平对齐。
- 视频解析和拍摄脚本解析改为结合前一帧、当前帧与后一帧判断人物动作阶段和运动趋势，减少对单帧画面的主观猜测。
- “确认镜头”右上角新增可持久化的实验性“首尾帧模式”；双向确认连续且场景不冲突的动作镜头会合并为一条首尾帧生成请求。
- 可灵图生视频提交支持真实尾帧参数，批量生成、时长和付费确认均按连续动作组计算。
- “生成视频”格支持直接播放、暂停和应用内全屏，生成与管理操作收纳到格子右下角悬浮菜单。
- 视频生成页原视频缩略图点击后，弹窗会自动从 I 点开始播放，无需再次点击播放按钮。
- 视频生成页“复刻分镜图”列支持点击进入全屏浏览，可缩放并切换其他可用镜头。
- 修复 Windows 下可灵 CLI 中文账号信息按系统代码页解码导致的顶部文字乱码。
- 首次进入视频生成页、切换到视频生成步骤或切换拍摄脚本时，会自动加载默认图生视频参数：可灵 o3、16:9、1080p；已保存的有效用户选择不会被覆盖。
- 修复可灵视频下载完成后 Windows 拒绝将 `.mp4.part` 重命名为最终文件的问题；写入句柄会在落盘前显式刷新并关闭，重命名失败时自动回退复制。
- 生成视频文件名统一为“镜头号+版本号”，例如 `镜头005-v1.mp4`，并自动迁移历史超长生成目录配置。
- 原视频列新增视频帧缩略图，点击缩略图即可弹窗播放对应 I/O 区间。
- 设置页新增“播放视频帧前后（秒）”，默认 1.5 秒，可在 0.1–30 秒范围内自定义并持久化。
- 可灵下载失败提示新增官方 24 小时结果 URL 有效期说明，提醒及时保存。
- 修复视频生成页误报“原视频不可用”：源帧关联缺失时会按帧路径和镜号恢复定位，缓存视频缺失时回退原始视频文件。
- 修复可灵视频已生成但因 Windows 超长目录导致下载失败；输出目录改用受限长度，并支持直接“重新下载”既有结果而不重复付费生成。
- “合成提示词”步骤改为“原图 / 复刻分镜图 / 生成提示词”三列；镜头信息变化后提示词列恢复为空，等待用户主动合成。
- 每个镜头会同时生成即梦规则版和可灵提示词，支持切换、编辑、复制，并将选中版本同步给视频生成。
- “确认镜头”的自动解析会补齐音效设计、建议时长和运镜；对白继续完全由用户手动填写，不会被解析覆盖。
- 新增可灵中国区一键视频生成：复刻流程扩展为四步，并在“拍摄脚本”和“导出”之间新增独立“视频生成”页面。
- 视频生成支持动态模型/参数、可灵与即梦原提示词切换、单镜头/批量付费确认、最多两路提交、无水印优先下载和历史版本管理。
- 原视频参考改为复用源文件的 3 秒 IO 点预览，不截取、不转码、不产生额外视频片段，避免工程磁盘占用膨胀。
- 可灵任务失败、取消或 15 分钟超时不会自动重新扣费提交；软件重启后只恢复查询已有 generationId。
- 一键复刻的“准备资产”页新增复刻补充说明；提交前会自动清理与用户要求冲突的提示词，并以用户要求为准生成新分镜。
- 支持明确移除原人物的耳环、眼镜、帽子、包、手表、发饰等配饰，避免将原人物外观完整复刻到新分镜中。
- 修复拍摄脚本表格长文本未充分使用单元格高度的问题。
- 修复准备资产页“全部折叠”后仍显示空白面板和逐镜箭头的问题；切换页面返回后会恢复可用的紧凑资产行。
- 修复一键复刻进行中切换页面返回后，进度状态可能被脚本同步刷新提前清除的问题。
- 多维度分析已移除“商业创意规则（ABCD + Hook-Body-Close）”分组，不再对其生成解析结果。
- 多维度分析结果按“证据、商业作用、优化建议”分行展示，阅读重点更清晰。
- 拍摄脚本资产自动绑定改为本地受控名称/别名匹配，不再上传镜头或资产图片调用视觉模型。
- 资产库支持维护匹配别名；重名资产不会自动绑定，避免错误关联。
- 删除视频自动故事板或其资源组时，保留视频解析页面的源视频帧；关联的自动拍摄脚本会同步移除。
- 视频解析页面的“生成故事板”现在会同时生成或恢复选定视频的故事板和拍摄脚本。
- 新建故事板描述默认字号调整为 12。

> Windows 安装包当前未使用公共代码签名证书，部分设备可能显示 SmartScreen 提示。
