## 本次更新

- 修复“构建脚本”完成后镜头组时长全部变为 0 的问题：单镜头和多帧组会依据画面动作、状态变化、运镜复杂度与参考帧数量生成 3–12 秒的合理默认值；普通镜头组总时长统一写入并读取组尾，确认页、生成页和实际任务不再出现组首/组尾分裂。
- 视频生成工作区由四列扩展为五列，新增可编辑“时长”列。用户可保留智能默认值或手动输入；输入会按当前后端支持范围归一，并同时更新页面时长、提示词中的“X秒视频”、视频任务 `durationSeconds` 和真实 HTTP API/可灵 CLI 的 `duration` 参数。
- 构建脚本不再要求视频按具体每秒执行动作：即使所选完整官方 Skill 含逐秒模板，当前镜头也只保留自然的“开头、随后、接着、最后”事件顺序和一次总时长；视觉模型返回的“第 N 秒”或“0-N 秒”标签会被清理。提示词规则升级至 19，旧缓存会自动进入待重新合成状态。
- 严重修复“确认镜头”构建脚本后切换到其他页面，返回时已构建状态被重置、“生成反馈”输入列消失的问题；提示词因资产或替换要求变更而进入待重拼状态时，已构建稿仍会持续显示并可填写反馈。
- 准备资产页手动“一键替换产品”改为即时并发提交：同一脚本的前一个复刻任务尚未结束时，其他镜头点击后会立即进入视觉分析和图片生成 API，不再被脚本级单任务锁静默拦截；页面忙碌状态会保留到全部并发任务结束。
- 修复“确认镜头”已构建视图中“生成反馈”文本框输入异常卡顿的问题：连续输入先保留在控件本地，停止输入或离开文本框后再合并保存一次，不再逐字同步替换整份镜头列表并刷新页面；反馈仍会自动持久化并正常触发局部重构。
- “构建脚本”彻底移除自动镜头划分：视频导入、视觉解析、构建和后续镜头组展示都不再根据场景、动作或模型结果自动补连。镜头范围完全以用户手动设置的首帧和结束帧为准；同一范围内的首帧、中间帧和结束帧按时间顺序合并进同一个视觉 API 请求，未设置范围的帧各自独立。视觉模型返回的连续性字段不能再覆盖手动分组。提示词规则升级至 18，旧分组缓存会自动失效。
- 修复普通多帧镜头组在拍摄脚本显示 4 秒、生成任务却只提交组首 1 秒的问题；关闭首尾帧模式时，实际 API/CLI 时长和 H3 提示词现统一使用拍摄脚本显示的组尾时长，显式首尾帧模式仍按连续片段累加。提示词规则升级至 17，旧的错误时长缓存会自动失效。
- 软件已内置 MiniMax-H3 的 8 个官方中文 `SKILL.cn.md` 及其全部必要引用文档，共 15 个上游原始文件，不再打包或加载重复的英文 `SKILL.md`；选择叙事风格后，“构建脚本”会让视觉模型读取对应完整中文正文，再按完整步骤、门禁、模板、画面材质、叙事结构、镜头节奏、动作连续性、声音策略和质检规则解析镜头。资源缺失时会中止并报错，不再静默退回泛化摘要。提示词规则升级至 16。
- 叙事风格选择器新增官方 Skill 来源和完整读取状态；最终 H3 提示词仍叠加所选风格的成片锁，避免完整 Skill 在视觉分析后的本地拼接阶段被弱化。
- “确认镜头”的“构建脚本”现在按视觉 API 额度并发处理不同镜头组，大幅减少多镜头脚本的等待时间；同一镜头组的多张图仍按时间顺序合并到一次多模态 API 请求中，不会拆分成多次解析。
- 恢复“匹配资产图”步骤右侧资产库：重新显示按类型分组的资产缩略图卡片与管理入口；“上传资产”和“按描述生成”统一移入资产管理页面，点击“自动匹配资产”会继续按名称/别名将资产库内容绑定到对应镜头。
- 视频生成页现在会在打开工程时扫描已完成成片：如果用户在文件夹中手动删除了实际 MP4，对应的视频生成和作品管理记录会自动移除，不再显示失效占位。扫描仅作用于已完成/部分完成记录，失败、取消、排队和生成中的任务会保留。
- 修复取消视频生成后任务状态被后台恢复查询重新写成“生成中”的问题：取消标记现会传递给普通生成、手动继续查询、启动恢复和超时恢复流程；任何延迟返回的旧状态都不能覆盖已取消任务。已取消任务不再反复显示“视频生成中”。
- 修复视频生成页“生成提示词”输入框无法连续键入的问题：草稿每次保存不再销毁重建输入控件；现在支持正常的中英文直接输入、中文输入法组合和粘贴，外部切换提示词版本时仍会立即同步文本。
- 按可灵官方多图参考与 O3/3.0 Omni 用法重写可灵提示词：参考图负责主体、服装、产品和场景一致性，正文只保留连续动作、核心运镜、必要环境与用户明确约束；普通多帧不再输出内部镜号、逐段秒数、摄影分析证据和重复声音规则，自动提示词控制在 500 字以内。提交阶段只补缺失的资产编号，不再复述服装细节和长篇一致性禁令。提示词规则升级至 15。
- H3 参考素材说明不再输出“依次对应镜头4至6”或“图片2是镜头5的动作参考”等仅应用内部可理解的拍摄脚本镜号；视频模型现在只接收图片编号、顺序用途和连续性要求。提示词规则升级至 14。
- H3 合成提示词不再自动拆分“0–1.7秒、1.7–3.3秒”等阶段时间区间；单镜头使用自然画面描述，多帧使用“开头、随后、接着、最后”的事件顺序，只保留一次视频总时长，也不会凭空添加 Logo 或其他用户未输入的精确时间事件。提示词规则升级至 13。
- 重写 MiniMax H3 本地提示词编译规则：普通多帧镜头组改为一条顺序动作参考，场景、运镜、光影、色彩和焦点只在组级描述一次；各时间段仅保留动作变化，不再输出多帧证据、原始运镜、摄影备注和重复声音段落。
- 修复 H3 首尾帧提示词与真实 API 模式不一致的问题：只有双帧且无额外资产时使用精确首尾帧语义；含中间帧或资产时统一使用多参考图语义。
- 修复结构化分析中的服装/道具在清洗后被重新注入，以及视频提交前再次拼接整段参考素材说明的问题；现在先合并后清洗，并且只补提示词中缺失的资产编号。提示词规则升级至 12。
- 修复 Windows 下可灵 CLI 提交较长中文提示词时立即出现 `FormatException: Missing extension byte` 的问题；应用现在绕过 `cmd.exe` 直接启动可灵 Node CLI，并能兼容解码本地控制台错误信息。
- 修复“根据反馈重构”成功后反馈数据虽已清空、输入框却仍显示旧文字的问题；反馈框现在会立即同步为空，同时保持正常输入时的光标和中文输入法状态。
- 修复反馈重构后“合成提示词”页没有自动补齐最终提示词的问题：反馈镜头重新拼接，未反馈镜头沿用原结果，缺失或失败的旧提示词会自动补齐，并按完整合并镜头组一次性写回。
