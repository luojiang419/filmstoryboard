# 103：动态产品槽位数量不能复用人物数量

## 问题

准备资产旧逻辑默认“一位人物对应一件产品”，因此用人物数量同时决定模特格和产品格数量。真实原帧可能只有一位人物，却同时识别到上衣、裤子、鞋等多个独立产品；此时第三件及后续产品会落入普通补充资产，生成前仍被判定为没有绑定对应产品槽位。

## 原因

- 人物和产品是两组独立识别结果，二者数量没有一一相等的保证。
- 产品槽位的 `slotIndex` 已由原帧分析给出，不能再以 `personCount` 截断。
- UI 即使显示了动态产品格，自动匹配若仍按人物数量分配 `sortOrder`，生成控制器也无法恢复正确的产品 A/B/C 关系。

## 正确做法

1. UI 直接按 `ReplicateShotGuide.subjects` 创建人物与产品动态格。
2. 自动匹配分别接收每个镜头实际识别到的产品数量，并为产品 A/B/C……预留稳定 `sortOrder`。
3. 生成前提示按同类型主体数量生成模特或产品后缀，不再复用人物数量。
4. 测试至少覆盖“一位人物、三个产品”，确认三件产品分别进入产品 A、产品 B、产品 C。

## 回归检查

- 单人物单产品仍显示无后缀的“模特/产品”。
- 多人物、多产品按各自识别数量独立编号。
- “移除”不要求绑定；“替换”必须命中相同类型与 `slotIndex` 的资产。
- 旧产品细节、场景和其他绑定作为补充资产保留，不抢占动态主体格。
