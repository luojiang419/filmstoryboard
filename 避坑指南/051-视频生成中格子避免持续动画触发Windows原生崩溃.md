# 051-视频生成中格子避免持续动画触发 Windows 原生崩溃

## 问题

视频生成阶段出现 `filmstoryboard.exe` 闪退。Windows 事件日志显示 1.0.0.174、1.0.0.175、1.0.0.178 均为 `flutter_windows.dll` 的 `0xc0000005` 访问冲突，异常偏移集中在 `0x0000000000d150xx`。

## 误判

曾怀疑是生成视频完成态格子内联播放器自动加载导致，所以将完成态改成“点击预览才加载播放器”。但 1.0.0.178 在移除完成态内联播放器后仍然闪退，说明真实原因不在完成态播放器。

## 真实风险点

生成中格子存在每个任务一个 `Timer.periodic`，并同时渲染持续运行的 `CircularProgressIndicator`。批量生成时多个格子持续重绘，容易把 Flutter Windows 原生层或显卡渲染路径推到不稳定状态，表现为 `flutter_windows.dll` 访问冲突，而不是 Dart 层可捕获异常。

## 处理方式

- 生成中格子不要使用持续动画和每秒计时器。
- 等待时长可以在任务轮询导致页面刷新时重新计算，不需要每秒刷新。
- 控制器异步生成/恢复任务完成后要检查是否已释放，释放后不再回调 UI。
- 不要把“页面关闭/控制器释放”接到任务服务的 `isCanceled`，否则会把远端仍在生成、可恢复查询的任务错误标成取消。

## 后续规避

涉及 Windows Flutter 大量列表/格子/表格时，避免给每个单元格创建持续动画、定时器或播放器。优先使用静态状态、按轮询刷新，完成态再按需加载媒体组件。
