# 027-版本递增必须同步更新配置与安装脚本

## 问题

按版本规则递增 `pubspec.yaml` 的 build number 后，如果没有同步更新应用更新配置和 Inno Setup 安装脚本，完整测试会失败。

失败用例：

```text
test/features/updater_service_test.dart
AppUpdateConfig current version matches pubspec build and installer version
```

典型错误：

```text
Expected: '1.0.0.151'
Actual: '1.0.0.150'
```

## 原因

项目通过测试强制校验三处版本一致：

- `pubspec.yaml` 的 `version: 1.0.0+build`
- `lib/features/updater/domain/app_update_config.dart` 的 `currentVersion/currentVersionTag`
- `installer/filmstoryboard.iss` 的 `MyAppVersion`

其中 `pubspec.yaml` 的 `1.0.0+151` 会被测试转换为 `1.0.0.151`，再与更新配置和安装脚本对比。

## 解决方式

每次递增版本时同步修改三处。

```yaml
version: 1.0.0+151
```

```dart
static const currentVersion = '1.0.0.151';
static const currentVersionTag = 'v1.0.0.151';
```

```iss
#define MyAppVersion "1.0.0.151"
```

## 验证命令

优先跑版本一致性测试：

```powershell
D:\flutter\bin\flutter.bat test test\features\updater_service_test.dart
```

发布或全局改动后继续跑：

```powershell
D:\flutter\bin\flutter.bat analyze
D:\flutter\bin\flutter.bat test
D:\flutter\bin\flutter.bat build windows --release
```
