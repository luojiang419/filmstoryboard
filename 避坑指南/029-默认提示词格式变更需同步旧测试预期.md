# 029-默认提示词格式变更需同步旧测试预期

## 问题

将“合成提示词”默认格式从 SD2 改为可灵官方格式后，完整 `flutter test` 中旧测试仍断言 `ShotPrompt.prompt` 必须包含 SD2 资产描述，例如“白衬衫人物”。

## 原因

旧逻辑中：

```dart
prompt: result.prompt,
selectedPromptFormat: sd2,
```

新逻辑中：

```dart
prompt: klingPrompt,
selectedPromptFormat: kling,
```

因此 `ShotPrompt.prompt` 的语义从“SD2 当前文本”变成“当前选中的可灵官方格式文本”。SD2 仍存在，但需要通过 `promptTextFor(prompt, ShotPromptFormat.sd2)` 读取。

## 解决方式

测试应拆开验证：

- 默认格式：`promptFormatFor(prompt) == ShotPromptFormat.kling`
- 可灵当前文本：`prompt.prompt` 包含可灵官方格式开头
- SD2 资产绑定：`promptTextFor(prompt, ShotPromptFormat.sd2)` 仍只包含当前镜头已确认资产

## 后续注意

- 修改默认格式、默认模型、默认 Provider 时，要全局搜索旧测试是否直接断言“当前文本”等于旧默认。
- 双版本提示词结构中，`ShotPrompt.prompt` 表示当前选中版本，不等价于固定 SD2 或固定可灵。
