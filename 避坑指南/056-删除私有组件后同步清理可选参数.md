# 056-删除私有组件后同步清理可选参数

## 问题现象

删除只被旧 UI 使用的私有组件后，`flutter analyze` 可能继续报与旧组件配套的残留参数：

```text
warning - A value for optional parameter 'logicalWidth' isn't ever given
```

本轮移除拍摄脚本外层资产库侧栏后，`_CompactLibraryAssetCard` 不再使用 `_LibraryAssetPreview(item, logicalWidth: 58)`，导致 `_LibraryAssetPreview` 的可选参数只剩默认值路径。

## 原因

Dart 分析器会检查私有元素和私有参数的实际调用情况。删除旧组件时，如果只删了主要 Widget，没有同步检查它们曾经传入的辅助参数，就会留下 `unused_element_parameter` warning。

## 处理方式

删除旧私有组件后，立刻用 `rg` 复查相关类名、key 和参数名：

```powershell
rg -n "_OldWidget|old-key|oldParameter" lib test
```

如果参数只剩默认值，不要为了压 warning 保留无意义配置；直接把参数移除，并在内部使用原默认值。

本轮修复方式：

```dart
// 修改前
const _LibraryAssetPreview(this.item, {this.logicalWidth = 256});
final double logicalWidth;

// 修改后
const _LibraryAssetPreview(this.item);
```

## 后续避坑

- 删除私有 UI 组件后必须跑 `flutter analyze --no-version-check`。
- 对被删组件调用过的辅助组件参数，用 `rg` 做一次二次复查。
- 如果只是单一路径常量，优先内联默认值，避免保留没有实际配置入口的参数。
