# 033-空画板同步与路径分隔符测试

## 问题 1：空画板签名会误判为未变化

现象：新增空画板后，同步器没有自动创建拍摄脚本。

原因：同步器用 `_boardSignature` 判断变化。新空画板的签名是空字符串，不存在的旧画板传入 `null` 后签名也是空字符串，导致 `'' == ''`，新画板被忽略。

解决：
```dart
if (_boardsById[board.id] == null ||
    _boardSignature(_boardsById[board.id]) != _boardSignature(board))
```

后续避免：凡是用签名判断列表实体变化时，新增实体必须先通过 id 是否存在判断，不要只比较内容签名。

## 问题 2：Windows 路径分隔符导致等价路径测试失败

现象：测试中期望路径包含 `/`，实际路径包含 `\`，但两者指向同一个文件。

解决：测试断言使用 `path.normalize` 后比较。

```dart
expect(
  p.normalize(actualPath),
  p.normalize(expectedPath),
);
```

后续避免：Windows 项目里不要直接字符串比较文件路径，尤其是经过 `File.path`、`path.join` 或手写路径混用之后。
