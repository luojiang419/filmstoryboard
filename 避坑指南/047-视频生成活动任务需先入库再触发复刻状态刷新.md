# 047-视频生成活动任务需先入库再触发复刻状态刷新

## 问题
点击生成视频后，如果只把 `submitting` 临时任务写入 `VideoGenerationController.value.tasks`，随后调用：

```dart
_replicateController.updateVideoGenerationStatus(ProcessingStatus.running);
```

会触发视频生成 controller 的来源刷新，`_refreshData()` 会重新从数据库读取任务列表。由于临时任务没有入库，页面又回到没有任务的状态，格子继续显示 `尚未生成`。

## 解决方式
活动任务必须在触发复刻状态刷新前先写入 `VideoGenerationRepository`：

```dart
for (final task in activeTasks) {
  _repository.upsertTask(task);
}
```

然后再更新页面状态和复刻状态。

## 后续避开
- 任何依赖 `value.tasks` 的视频生成状态，如果会被 `_refreshData()` 读库覆盖，都必须先入库。
- 不要只在内存里插入任务状态，除非能确认不会触发其他 controller listener。
