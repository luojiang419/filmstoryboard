# 032-表格内新增同名按钮需避免文本唯一断言

## 问题
视频生成列新增中央“生成视频”按钮后，页面测试中原本用于校验表头的 `find.text('生成视频')` 从 1 个变成 2 个，导致测试失败。

## 现象
`flutter test test\features\replicate_page_test.dart` 报错：

```text
Expected: exactly one matching candidate
Actual: Found 2 widgets with text "生成视频"
```

## 原因
测试把表格里的同名文案当成唯一元素校验。新增按钮后，表头和按钮都在同一个表格范围内，文本不再唯一。

## 解决方式
- 表头存在性断言从 `findsOneWidget` 调整为 `findsWidgets`。
- 给新增按钮补稳定 key：`generated-video-generate-button-${shot.id}`。
- 用 key 精确断言按钮存在和禁用状态，避免继续依赖同名文本数量。

## 后续避坑
- 页面里新增与表头、标签、菜单项同名的按钮时，不要使用裸 `find.text` 做唯一性断言。
- 交互控件优先添加稳定 key，用 key 校验位置、状态和点击行为。
