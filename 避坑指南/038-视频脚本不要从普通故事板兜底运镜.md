# 038-视频脚本不要从普通故事板兜底运镜

## 问题

视频解析后 UI 拍摄脚本仍显示“缓慢推近主体”，即使视频帧解析和提示词已经强化了同镜头升降/上摇判断。

## 根因

这类问题不一定来自视觉模型本身。排查数据库时要分层看：

1. `video_frame_analyses.dimensions_json.cameraMovement`
2. `video_shots` / `video_shot_frames`
3. `script_shots.source_video_frame_id`
4. `script_shots.camera_movement`

本次真实工程库中：

```text
video_shots = 0
video_shot_frames = 0
script_shots.source_video_frame_id = NULL
raw_response 不含 组级运镜复核
```

说明脚本是从普通故事板图片同步来的，运镜字段来自脚本层兜底，而不是视频解析组级复核。

## 修复原则

1. 没有焦点帧时，视频镜头组不能为空，应退回使用所有已完成解析帧。
2. 自动创建视频拍摄脚本时，应优先使用 `video_frame_analyses` 和 `video_shots`，不要只从故事板图片生成空白脚本。
3. 自动脚本应保留：
   - `sourceVideoFrameId`
   - `sourceStoryboardAssetId`
   - `sourceVideoId`
   - `sourceStoryboardId`
4. 看到 UI 仍显示错误运镜时，先检查安装目录 exe 版本，避免实际运行旧版本。

## 后续注意

旧数据不会因为代码更新自动改正。安装新版本后，需要重新解析视频或重建拍摄脚本，才能让 `video_shots` 和 `source_video_frame_id` 正确生成。
