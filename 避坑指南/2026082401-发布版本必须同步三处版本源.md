# 发布版本必须同步三处版本源

## 问题

Windows 安装包的版本由 Flutter 产品版本、应用更新器版本和 Inno Setup 版本宏共同决定。只改 `pubspec.yaml` 会导致更新器显示或安装包契约校验失败。

## 解决

统一使用 `scripts/prepare_release.py --version 1.0.0.339`，一次性同步：

- `pubspec.yaml`
- `lib/features/updater/domain/app_update_config.dart`
- `installer/filmstoryboard.iss`

最后使用 `scripts/verify_release_artifact.ps1` 校验 EXE 产品版本、安装包版本、内置依赖、模型哈希和 SHA-256。
