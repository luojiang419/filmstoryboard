# 028-首尾帧缩略图Key避免复用

## 问题

首尾帧模式下，如果当前镜头没有连续尾帧，尾帧占位格容易复用当前镜头的 `shot.id` 和原来的缩略图 key。

表现为 Widget 测试中点击 `replicate-shot-replica-thumbnail-{shotId}` 时找到多个组件，实际 UI 交互也可能出现点击目标不稳定。

## 原因

首帧复刻格和尾帧占位格都使用了：

```dart
'replicate-shot-${showOriginal ? 'original' : 'replica'}-thumbnail-${shot.id}'
```

当尾帧为空但组件内部仍传入当前 `shot` 作为占位时，两个复刻缩略图 key 完全一致。

## 解决方式

为尾帧相关格增加独立后缀：

```dart
keySuffix: 'tail-original'
keySuffix: 'tail-replica'
```

并在 key 中拼接：

```dart
'...-${shot.id}${keySuffix.isEmpty ? '' : '-$keySuffix'}'
```

## 后续注意

- 动态增加表格媒体列时，不能只依赖 `shot.id` 作为唯一 key。
- 同一行内存在同类型缩略图时，应把语义位置也写进 key，例如 `start`、`tail`、`original`、`replica`。
- 测试点击缩略图前，要确认 finder 只匹配一个目标。
