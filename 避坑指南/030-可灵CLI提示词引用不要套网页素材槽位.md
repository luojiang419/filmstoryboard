# 030 - 可灵 CLI 提示词引用不要套网页素材槽位

> 2026-08-04 更新：本记录已被 `031-可灵Omni提示词必须按whoami输入编号引用.md` 修正。当前可灵 3.0 Omni 的 `who_am_i` 明确要求 prompt 使用 `图片1`、`图片2` 引用 `image_1..image_7`，不要再按本文件旧结论把新提示词改成“输入图片”。本文件只保留为历史踩坑记录。

## 问题

核对可灵官方 CLI 指南后确认，项目实际使用的是 `kling image_to_video --image <url|path> <prompt>`，图片通过 CLI 参数显式传入，而不是通过网页端多素材槽位上传。

## 本次踩坑

把可灵提示词从旧的“以图片1作为首帧...”改为 CLI 友好的“以输入图片作为首帧...”后，旧测试仍断言 `图片1`，导致聚焦测试失败。

## 避免方式

- 可灵 CLI 图生视频提示词优先写“输入图片”“尾帧”等参数语义。
- 兼容历史草稿时保留 `图片1`、`@图片1` 的识别即可，不要把新提示词强行改成网页端 `@图1/@图片1`。
- 修改可灵提示词开头时，同步更新 `replicate_controller_test.dart` 和 `video_generation_assets_test.dart` 中的旧基线。
