# 旧 Windows 宿主缺少文件选择通道导致添加视频无响应

[CODEX_LONG_TASK_CONTINUE_V3]

## 表现与证据

“解析视频”页点击“添加视频”没有文件选择框，拖拽视频仍能正常导入。本机 2026-10-25 的 `data/logs/file_dialog.jsonl` 连续记录：

```text
source: video_analysis.pick_video
operation: openFiles
phase: failed
MissingPluginException(No implementation found for method openFiles on channel filmstoryboard/native_file_dialog)
```

出现该错误的已安装 EXE 版本为 `1.0.0+361`。这是宿主未注册新版原生通道的证据，不能据此断言为文件过滤器、按钮绑定或视频解析服务故障。拖拽直接调用 `importVideos`，不经过文件选择框，因此仍然有效。

## 处理方法

- `DesktopFileDialogService` 继续优先使用独立 STA 原生文件选择通道。
- 仅 Windows 路由遇到 `MissingPluginException` 时，回退到已有 `file_selector` 插件。单选、多选和保存都保留原始参数、安全初始目录和全局互斥锁，并记录 `fallback / missing_native_channel` 事件。
- 用户取消、`PlatformException` 等真实原生错误不触发回退，避免重复弹窗或重复提交。
- 视频页捕获选择或导入失败，显示“添加视频失败，请重试或拖拽视频到此页面”，不再把错误留作未捕获异步异常；页面退出后不再处理返回的选择结果。
- 安装更新时使用完整安装包，确保 EXE、Flutter 运行库、`data/app.so` 和其他资源来自同一构建；不要只替换 Dart 资源文件。
