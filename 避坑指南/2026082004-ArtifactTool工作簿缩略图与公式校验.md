# ArtifactTool 工作簿缩略图与公式校验

## 问题 1：内置 PNG 渲染未显示嵌入图片

### 现象

`workbook.render()` 能正确渲染单元格、样式和行列尺寸，但本轮预览 PNG 的图片列为空；`workbook.inspect({ kind: "drawing" })` 已能看到图片锚点。

### 处理

不能仅凭预览 PNG 判断 XLSX 丢图，应继续验证导出包和真实 Excel 对象：

1. 检查 XLSX ZIP 中的 `xl/media/` 与 `xl/drawings/`；本轮共存在 20 个 JPEG 媒体对象和两个 drawing 文件。
2. 用 Excel 只读打开最终工作簿，检查工作表 `Shapes.Count`；“选择总览”和“完整提示词”均为 10。
3. 保留 ArtifactTool 的 drawing inspect 结果，确认锚点行列和尺寸。

结论：这是内置预览渲染对绘图对象的显示差异，不是导出的 XLSX 缺失缩略图。

## 问题 2：选择计数公式范围偏移

### 现象

结果数据实际位于 `G8:G17`，首版公式误写为 `G9:G18`，会漏计 T01 并多包含一个空行。

### 修复

统一改为：

```excel
="已入选"&CHAR(10)&COUNTIF(G8:G17,"入选")&" / 2"
```

最终用 Excel 只读打开，确认初始显示为“已入选 0 / 2”。后续工作簿生成脚本应从首条数据行和结果数计算范围，避免手写偏移。

## 问题 3：ISO 时间被识别为日期序号

### 现象

直接写入 `2026-08-20T...Z` 时，渲染器将其识别为日期数值并显示 Excel 序号。

### 修复

对只用于说明的时间加文本前缀 `UTC `，确保以字符串显示；需要参与计算时则应写真实 `Date` 并设置明确日期格式。
