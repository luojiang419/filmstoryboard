# 014 - 复刻测试的 API 卡片必须与模型协议匹配

## 现象

复刻控制器测试未进入模拟图片生成服务，所有镜头直接失败，错误提示当前默认 API 卡片是 GRSai，不能用于 Gemini 模型。

## 原因

图片生成提供方解析器会校验激活 API 卡片的协议是否与当前模型一致。测试将模型改成 Gemini 后，仍继承了默认的 GRSai 卡片，解析器会在请求前抛出 `FormatException`。

## 处理

在只验证控制器提示词的测试中清空 API 卡片列表，使解析器按 Gemini 默认连接分支运行；若要验证卡片行为，则显式构造与模型协议相同的测试卡片。

## 后续规避

凡是测试替换 `imageGenerationModel`，同时检查 `activeImageGenerationApiConfigId` 与卡片模型协议。不要把协议不匹配误判为图片生成或提示词逻辑故障。
