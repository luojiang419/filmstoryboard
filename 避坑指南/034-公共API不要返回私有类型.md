# 034 - 公共 API 不要返回私有类型

## 问题

新增 `MiddleDragAutoScrollController.resolveTargets` 时，方法是公共的，但返回值 `_ActiveMiddleDragTargets` 是库内私有类型，触发 Flutter 分析提示：

```text
Invalid use of a private type in a public API - library_private_types_in_public_api
```

## 原因

Dart 以库为边界控制私有类型。公共类中的公共方法会成为外部可见 API，如果它的签名暴露 `_` 开头的私有类型，外部调用方无法合法引用该类型，分析器会报错。

## 解决

该方法只在 `middle_drag_auto_scroll.dart` 内部使用，因此改为私有方法：

```dart
_ActiveMiddleDragTargets? _resolveTargets(Offset globalPosition) {
  ...
}
```

调用处同步改为：

```dart
final targets = widget.controller._resolveTargets(event.position);
```

## 后续避免

- 公共 Widget/Controller 的公共方法签名不要出现 `_PrivateType`。
- 如果方法只给同一文件内部协作使用，直接使用私有方法。
- 如果确实要暴露给外部，创建公共 DTO 或改为返回外部不需要感知的公共类型。
