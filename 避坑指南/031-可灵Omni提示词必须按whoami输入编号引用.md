# 031 - 可灵 Omni 提示词必须按 who_am_i 输入编号引用

## 问题

曾经为了适配 CLI 本地上传，提示词写成“以输入图片作为首帧和主体外观参考”。但当前官方 `kling who_am_i --quiet` 已明确声明：`kling-video-v3_0_omni` 图生视频输入是 `image_1..image_7`，提示词应通过 `图片1`、`图片2` 等编号引用。

## 正确做法

- 普通图生视频：写 `以图片1作为首帧和主体外观参考`。
- 首尾帧 / 多图参考：写清 `图片1` 是首帧，`图片2` 是尾帧或对应参考图。
- 生成或提交前必须读取 `who_am_i` 的模型 `inputs`，不要只看 `arguments`。
- 如果模型只声明 `first_image`，没有 `tail_image` 或 `image_2`，不能提交首尾帧任务。

## 避免再次踩坑

后续可灵 CLI 或模型升级时，以 `kling who_am_i --quiet` 的实时声明为准；旧快照或旧避坑记录里的提示词写法只能作为历史兼容参考，不能覆盖官方当前声明。
