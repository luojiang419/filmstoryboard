# 新增检查器按钮后必须修正滚动测试与三处版本

## 问题

故事板参数面板顶部增加桥接按钮后，旧 widget test 直接点击下方“生成线稿分镜”会命中屏幕外位置；版本只改 pubspec 还会让 updater 测试发现 AppUpdateConfig 和 Inno Setup 不一致。

## 处理

- Widget test 在打开线稿区前先 `ensureVisible`，检查下方区域后通过 inspector ListView 向顶部 fling，再操作标题对齐控件。
- 每次 build number 递增必须同步：`pubspec.yaml`、`AppUpdateConfig.currentVersion/currentVersionTag`、`installer/filmstoryboard.iss`。

## 验证

全量 796 项测试通过；Windows release 构建成功。
