# 008-高清重绘并发替换与右侧面板测试滚动

## 背景

故事板拼图页新增“高清重绘”区块后，需要同时验证两类行为：

- 多张图片并发提交并在返回后逐格替换。
- 右侧参数面板新增折叠区后，旧 Widget 测试仍能稳定点击原有区块和开关。

## 坑 1：并发替换不能只等全局生成标记

现象：

- 测试释放两个并发生成任务后，只等待 `!controller.value.isGeneratingImage`，偶发出现一个格子仍是旧 asset。
- 测试失败后 teardown 关闭数据库，尚未完成的后台归档任务继续写库，触发 `Bad state: This database has already been closed`。

原因：

- 后台任务提交后是 `unawaited` 并发执行。
- 测试只看全局状态不够精确，应该等待业务目标本身完成。

处理方式：

```dart
imageService.releaseAll();
await _waitUntil(() {
  final board = controller.value.selectedBoard;
  return board != null &&
      board.items.length == 2 &&
      board.items.every(
        (item) => item.asset.id.startsWith('generated-cut-'),
      );
});
await _waitUntil(() => !controller.value.isGeneratingImage);
```

后续原则：

- 并发后台任务测试优先等待“目标资源/记录已经落地”，再等待 UI busy 标记清空。
- teardown 前必须确保所有 `unawaited` 任务已经实际结束，尤其是会写数据库或文件的任务。

## 坑 2：右侧面板新增区块会改变 Widget 测试点击坐标

现象：

- 新增“高清重绘”区块后，原测试里的 `tester.tap(find.text('图片编号').first)` 或 `tester.tap(find.text('多宫格布局'))` 出现 hit test miss。
- 标题位于视口顶部或底部附近时，坐标可能被顶部栏覆盖或处在滚动裁剪边缘。

处理方式：

```dart
await tester.ensureVisible(captionNumberSwitch);
await tester.pumpAndSettle();
await tester.tap(captionNumberSwitch);

await tester.drag(
  find.byKey(const ValueKey('storyboard-inspector-list')),
  const Offset(0, 96),
);
await tester.pumpAndSettle();
await tester.tap(find.text('图片编号').first);
```

以及：

```dart
tester.state<ScrollableState>(inspectorScrollable).position.jumpTo(0);
await tester.pumpAndSettle();
await tester.drag(inspectorScrollable, const Offset(0, -120));
await tester.pumpAndSettle();
await tester.tap(find.text('多宫格布局'));

tester.state<ScrollableState>(inspectorScrollable).position.jumpTo(0);
await tester.pumpAndSettle();
await tester.tap(find.byTooltip('收起画板参数'));
```

后续原则：

- 右侧滚动面板测试不要假设新增区块前的固定坐标还成立。
- 点击面板深处控件前先 `ensureVisible`；点击顶部按钮前先回到顶部。
- 如果新增更多区块，优先给关键按钮加稳定 key，测试用 key 定位，不用同名文字猜交互位置。
