# 039-安装包版本号升级后必须复核内部主程序版本

## 问题现象

安装包文件名、安装器 `AppVersion`、注册表 `DisplayVersion` 都显示 `1.0.0.159`，但软件左上角标题栏仍显示 `v1.0.0.158`。

## 根因

159 安装包外壳版本已经更新，但安装包内部携带的 `filmstoryboard.exe` 和 `data\app.so` 仍来自旧的 158 构建产物。安装器正常执行并返回成功，但它只是把旧内部产物重新安装了一遍。

## 快速判断方法

不要只看安装包文件名或注册表版本，必须复核安装目录真实文件：

```powershell
$f = Get-Item -LiteralPath 'D:\Program Files\filmstoryboard\filmstoryboard.exe'
$f.VersionInfo.FileVersion
$f.VersionInfo.ProductVersion
rg -a "filmstoryboard v1.0.0.159|v1.0.0.158" 'D:\Program Files\filmstoryboard\data\app.so'
```

还要看安装日志中主程序的内部时间戳：

```powershell
Select-String -LiteralPath '.\installer\install-1.0.0.159-repacked.log' `
  -Pattern 'filmstoryboard.exe' -Context 4,8
```

正确的 159 安装日志应出现：

```text
Dest filename: D:\Program Files\filmstoryboard\filmstoryboard.exe
Time stamp of our file: 2026-08-04 22:08:58.000
Successfully installed the file.
```

## 修复步骤

1. 重新构建 Windows Release：

```powershell
D:\flutter\bin\flutter.bat build windows --release
```

2. 重新编译 Inno Setup 安装包：

```powershell
ISCC.exe installer\filmstoryboard.iss
```

3. 重新生成 `.sha256`：

```powershell
Get-FileHash .\dist\installer\filmstoryboard-Setup-1.0.0.159.exe -Algorithm SHA256
```

4. 安装后复核：

```powershell
$f = Get-Item -LiteralPath 'D:\Program Files\filmstoryboard\filmstoryboard.exe'
$f.VersionInfo.FileVersion
$f.VersionInfo.ProductVersion
```

## 后续规避

发布前验收必须包含：

- `pubspec.yaml` 版本。
- `AppUpdateConfig.currentVersion/currentVersionTag`。
- `installer/filmstoryboard.iss` 的 `MyAppVersion`。
- 构建目录 `build\windows\x64\runner\Release\filmstoryboard.exe` 文件版本。
- 安装包安装后的 `D:\Program Files\filmstoryboard\filmstoryboard.exe` 文件版本。
- 安装目录 `data\app.so` 中的标题版本字符串。
- 安装包 SHA-256 与远端 Release 资产一致。

只有这些全部一致，才算 159 真正发布完成。
