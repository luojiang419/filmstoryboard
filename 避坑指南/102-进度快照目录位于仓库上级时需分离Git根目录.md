# 进度快照目录位于仓库上级时需分离 Git 根目录

## 现象

项目 Git 根目录是 `G:\data\app\film\filmstoryboard`，但进度快照统一保存在 `G:\data\app\film\进度快照`。把上级目录作为 `create_progress_snapshot.py --root` 后，快照文件能生成，但脚本内部的 `git status` 和 `git diff` 会报 `not a git repository`，并把帮助文本写进快照。

## 原因

该脚本把同一个 `--root` 同时用作快照输出根目录和 Git 命令工作目录，无法直接表达“快照在仓库上级、Git 在子目录”的项目布局。

## 正确做法

1. 不回改已经生成的递增快照。
2. 从 `G:\data\app\film\filmstoryboard` 执行只读 Git 状态与差异检查。
3. 使用 `apply_patch` 手工在 `G:\data\app\film\进度快照` 创建下一个纯递增快照，填写聚焦差异、验证结果、待办与下一步。
4. 不使用脚本输出的非仓库帮助文本作为有效交接依据。
