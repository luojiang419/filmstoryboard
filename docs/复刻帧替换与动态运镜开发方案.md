# 复刻帧替换与动态运镜开发方案

## 1. 任务目标

- 确认镜头步骤在表格最左侧显示原视频帧缩略图。
- 右侧资产库按人物、产品、场景、道具、视频、音频和其他参考分类展示。
- 资产匹配后支持单镜头替换人物/产品，并支持弹窗确认的一键批量复刻。
- 批量任务按镜号错峰提交，限制同时在途请求，逐条回填且失败可单独重试。
- 持久化原帧、复刻帧、资产引用、生成提示词、模型、状态和错误信息。
- 合成提示词步骤只把复刻版分镜作为左侧主缩略图。
- 按 Seedance 2 提示词规范结合主体动作和相邻景别趋势生成差异化运镜。

## 2. 模块拆分

1. 数据模型与数据库：新增 `ReplicatedShotImage` 和 `replicated_shot_images` 表，schema 升级到 6。
2. 图片复刻服务：复用现有 `ImageGenerationService.generateEditedImage`，原视频帧始终作为第一张参考图，后续按已确认资产顺序附加新参考图。
3. 单镜与批量调度：单镜直接提交；批量默认间隔 450ms、最大并发 3，镜头按 `shotNumber` 排序。
4. 界面展示：步骤 1 显示“原图 / 复刻”对照；步骤 3 显示“复刻分镜”，未生成时明确显示“待复刻”。
5. 资产库：保留右侧可拖拽资产库，改为按 `ReplicateAssetType` 分组并显示数量。
6. 动态运镜：显式动态运镜优先；固定或空运镜根据动作、方向、产品展示、空间揭示、航拍和相邻景别推断。

## 3. 请求与回填契约

```text
图片1：当前镜头原视频帧（构图、动作、光影基准）
图片2...n：当前镜头已确认的新人物/产品/场景/道具参考图
输出：复刻版静态分镜图
```

- 人物替换保留原姿态、表情、视线和动作阶段。
- 产品替换保留手部接触、摆放、包装结构、材质和比例。
- 场景/道具仅在对应资产已匹配时替换。
- 结果按镜头 ID 持久化，界面按镜号排序，因此网络完成先后不会打乱表格顺序。

## 4. 运镜推断规则

| 画面趋势 | 运镜 |
| --- | --- |
| 奔跑、追逐、行走、驶过、飞行 | 平稳跟拍 |
| 左右方向移动、转身、横向掠过 | 平稳横摇 |
| 拿起、展示、表情、产品细节 | 缓慢推近 |
| 全景、城市、建筑、环境揭示 | 缓慢拉远 |
| 环绕、旋转展示、转台 | 缓慢环绕 |
| 航拍、俯冲、高空、鸟瞰 | 航拍俯冲或升降 |
| 相邻镜头由大景别进入小景别 | 推近承接 |
| 相邻镜头由小景别进入大景别 | 拉远承接 |
| 无明显动作且明确要求固定 | 固定镜头 |

## 5. 验收标准

- 原帧和复刻帧展示位置、标签和缺失状态清晰。
- 分类资产库仍可拖拽到镜头，原自动匹配、确认和锁定逻辑不回退。
- 单镜按钮只在存在已确认绑定时启用。
- 一键复刻必须二次确认，并明确任务数、错峰间隔与并发上限。
- API 输入顺序稳定为原帧在前、新资产在后。
- 结果可在重启后恢复；失败状态和错误可见、可重试。
- 合成提示词按钮在全部已确认镜头都有复刻帧后启用。
- 奔跑、产品展示、空间揭示等镜头生成不同的动态运镜。
- `flutter analyze`、完整测试集和 Windows Release 本地构建通过。
