# 爆款复刻工作台功能补齐执行计划

> 基线文档：`docs/一键复刻爆款.md`、`docs/一键复刻UI布局确认版.md`  
> 当前决策：主菜单中的“多宫格裁切”改为“视频解析”；功能菜单支持底部和左侧两种布局，由设置页切换。

## 1. 任务目标

将当前零散的领域模型、数据库表和局部服务整理为可操作、可恢复、可导出的完整业务闭环：参考视频 → 视频解析 → 焦点帧故事板 → 拍摄脚本（内含复刻流程）→ 导出交付。

旧版裁切数据和服务保留用于已有工程兼容，但不再占用主菜单；图片生成页仍可打开兼容裁切工具，避免旧流程和历史数据突然失效。

## 2. 模块与文件清单

| 模块 | 主要目录/文件 | 目标 |
| --- | --- | --- |
| 导航与布局 | `lib/app/app_shell.dart`、`lib/features/settings` | 视频解析替换旧入口；底部/左侧菜单即时切换并持久化 |
| 视频解析 | `lib/features/video_analysis` | 视频导入、元数据、抽帧、质量筛选、逐帧解析、镜头汇总、恢复与报告导出 |
| 故事板联动 | `lib/features/storyboard` | 焦点帧与候选帧关联、剧情描述、顺序同步和可追溯原图 |
| 拍摄脚本 | `lib/features/shooting_script`、`lib/features/exporter` | CRUD、十列编辑、排序、模板导出、原图导出 |
| 拍摄脚本内复刻流程 | `lib/features/replicate` | 三步流程、资产引用、SD2 提示词、单项重试与批量导出 |
| 数据与迁移 | `lib/core/database/app_database.dart`、工程目录服务 | 旧工程无损迁移、任务状态恢复、路径统一 |
| 质量保障 | `test/` | 控制器/服务/页面测试、1280×720 布局、Windows 本地构建 |

## 3. 分步执行与验证

1. 导航与设置 → 验证旧主入口消失、视频解析入口可见、两套菜单切换后立即生效且重启保持。
2. 视频解析基础 → 验证导入视频后按视频建立目录，元数据与候选帧可恢复，重复/模糊帧可筛除。
3. 视觉解析与报告 → 验证单帧失败不阻断任务，四类报告格式可读且失败不残留临时文件。
4. 故事板与脚本 → 验证仅焦点帧进入故事板，脚本十列可编辑，原图与模板导出可追溯。
5. 一键复刻 → 验证三步状态可恢复，素材编号稳定，最终提示词符合 `SD2提示词规则.md`。
6. 全局回归 → 运行 `flutter analyze`、相关测试、完整测试和 Windows Release 本地构建。

- 主菜单不再显示“多宫格裁切”，对应位置为“视频解析”。
