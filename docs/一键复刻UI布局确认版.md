# 爆款复刻工作台 UI 布局确认版

> 版本：v2（沿用现有界面风格）  
> 状态：待确认，确认前不进入 UI 编码  
> 目标：只确定页面内容排版，不重做现有应用外壳、主题和组件风格

## 0. 本版必须遵守的原则

1. 页面外壳继续使用当前 `AppShell`：窗口标题栏 → 页面内容区 → 功能菜单。
2. 功能菜单支持底部和左侧两种布局，由设置页切换；两者复用同一份页签、路由和视觉状态，不使用抽屉导航。
3. 新页面只使用现有 `AppTheme`、`ColorScheme`、Material 3 控件、卡片、输入框和按钮。
4. 参考截图只借鉴内容结构：三步流程、镜头表格、资产分组卡片、最终提示词表；不照搬截图的深色主题或其他视觉参数。
5. 现有故事板和裁切页的三栏工作区、可折叠侧栏、顶部工具栏、间距和拖拽习惯继续作为新页面骨架。

### 2.1 排版说明

- 左侧沿用当前图片任务侧栏的可折叠模式，展开宽度优先沿用约 240px，收起后保留约 44px 轨道。
- 中央区域沿用当前画布面板，不新增全屏预览页；帧卡片可在网格与时间轴之间切换。
- 右侧沿用当前检查器面板，展开宽度优先沿用约 300px，收起后保留约 44px 轨道。
- 解析字段使用现有检查器的分组折叠方式；`解析维度.csv` 的营销字段放在“营销分析”折叠区，不把所有字段同时铺开。
- 处理中时沿用当前按钮禁用、进度文本、SnackBar 和错误提示方式，不另做进度中心。

### 2.2 多维度分析报告导出

视频解析页必须提供明确的主按钮：

```text
[导出 <视频文件名> 多维度分析报告]
```

按钮规则：

- 没有完成视频级汇总时按钮禁用，并提示“完成解析后可导出报告”。
- 报告已生成后按钮可用，点击打开当前风格的导出对话框，不直接弹出系统保存窗口。
- 对话框内保留当前导出页使用的 `SegmentedButton`、`FilledButton`、`OutlinedButton` 和进度反馈。

```text
┌──────────────────────────────────────────────┐
│ 导出多维度分析报告                            │
├──────────────────────────────────────────────┤
│ 报告名称                                      │
│ <视频文件名>视频多维度分析报告                │
│                                              │
│ 输出格式                                      │
│ [XLSX] [PDF] [PNG] [JPG]                     │
│                                              │
│ 导出范围                                      │
│ ○ 整份报告   ○ 仅概览   ○ 镜头明细            │
│                                              │
│ PNG/JPG 页面                                  │
│ ○ 导出全部页   ○ 仅当前页                    │
│                                              │
│ [选择目录]                    [取消] [导出]   │
└──────────────────────────────────────────────┘
```

输出规则：

| 格式 | 输出内容 | 文件命名 |
| --- | --- | --- |
| XLSX | 可筛选的结构化报告，包含概览、镜头明细、多维度分析、模型原始结果 | `<视频名>视频多维度分析报告.xlsx` |
| PDF | 多页视觉报告，保留标题、分组、镜头缩略图和分析文本 | `<视频名>视频多维度分析报告.pdf` |
| PNG | 按报告页渲染的无损图片；导出全部页时生成多个文件 | `<视频名>视频多维度分析报告-第01页.png` |
| JPG | 按报告页渲染的压缩图片；导出全部页时生成多个文件 | `<视频名>视频多维度分析报告-第01页.jpg` |

报告页面固定为：`多维度分析页`（首部）、`概览页`、`镜头明细页（按内容自动分页）`。镜头明细页左侧显示对应视频帧缩略图；XLSX 额外保留模型原始结果，PNG/JPG/PDF 不展示原始 JSON。

- PNG/JPG/PDF 沿用现有故事板导出的清晰度、进度、取消和临时文件清理习惯。
- PDF 必须是一个多页文件；PNG/JPG 默认一个报告页一个文件，避免生成不可阅读的超长图片。
- 导出过程中显示 `已完成页数 / 总页数`；失败时删除 `.part` 临时文件并允许重试。

## 5. 拍摄脚本页内的复刻流程

复刻流程嵌入拍摄脚本页，采用“顶部业务步骤条 + 下方现有面板内容”的排版。步骤条是页面内部组件，不是新的全局导航；从脚本页点击“开始复刻”进入，完成后可返回脚本编辑。

```text
┌────────────────────────────────────────────────────────────────────┐
│ 一键复刻：参考视频名                                                │
│ ① 确认镜头 ───────── ② 准备资产 ───────── ③ 合成提示词              │
│    11个镜头已就绪       0/9 已生成          0/11 已合成              │
├────────────────────────────────────────────────────────────────────┤
│ 页面工具栏：返回 / 保存 / 当前步骤操作 / 下一步                     │
├────────────────────────────────────────────────────────────────────┤
│                         当前步骤内容区                              │
└────────────────────────────────────────────────────────────────────┘
```

- 三步之间保持当前页内状态，切换步骤不丢失已编辑内容；关闭页面后通过控制器恢复。

## 7. 组件复用清单
