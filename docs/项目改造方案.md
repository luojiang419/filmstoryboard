将我的项目改造为“爆款复刻” 软件，核心功能需求如下：
1.输入视频后自动拆解帧

2.输入视频后使用ffmpeg拆解视频帧（测试使用关键帧变化还是逐帧更好）提取的视频帧按视频文件名创建文件夹进行存储。

3.自动解析视频帧的多维度的数据，解析模版在 “docs\解析维度.csv”里面，注意是逐帧解析后汇总，避免一次性全部丢给大模型导致上下文不足。
解析完成后出具“xx视频多维度解析.xlsx”报告,将用来给销售分析该视频的特点和以便预测未来宣传的方向。
当前软件的解析故事板功能已经是类似功能了，复用并作改造以适配新的业务需求。

4.故事版功能，将该视频创建多宫格故事板，然后将剧情的脉络描述都写在故事板下方。

5.拍摄脚本，脚本模版在使用我提供给你的图片的libtv官方模版，

6.一键复刻，这里是将提取的视频帧作为参考图，使用提供新的产品多视图和人物形象，然后生成一份于参考图一致的新的分镜图，实现精准复刻。最后生成新的一份视频拍摄脚本。
注意是逐帧解析后汇总，避免一次性全部丢给大模型导致上下文不足。，当前软件的解析故事板功能已经是类似功能了，复用并作改造以适配新的业务需求。

7.多模态模型对拍摄脚本根据官方“docs\SD2提示词规则.md”进行解析，实现符合SD2.0模型的最优化提示词，实现最好的生成效果。

9.增加导出脚本图片功能，实现导出脚本原图，以便到libtv进行生成

10.我提供三张流程参考图片，是从初步脚本-匹配资产-最终合成提示词，也就是libtv官方的脚本功能，你需要将它移植到功能里。

使用我本地部署的多模态模型学习官方“docs\SD2提示词规则.md”，解析画面后帮我写出适合SD2.0模型的最优化提示词，实现最好的生成效果。
多模态模型的 URL、API Key 和模型名称只在应用设置页的本机配置中填写，不写入方案文档或 Git 历史。
