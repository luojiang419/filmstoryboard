# 准备资产一键替换八组合提示词

版本：`deterministic-replacement.v1`

说明：M 表示模特资产，P 表示产品/服装资产，S 表示场景资产。以下内容由 `DeterministicReplacementPromptCatalog` 定义；实际生成时还会插入真实图片编号、主体处理计划、产品关系、动作、深度约束、文字与 Logo 白名单。

## M0-P0-S0 · 全部保留

```text
【确定性一键替换协议】
【组合路由】M0-P0-S0 · 全部保留：没有绑定替换资产的主体完整沿用图片1；只执行处理计划中显式要求的移除。
图片1是原视频帧，也是构图、机位、透视、主体位置、姿势、接触、遮挡和所有空资产槽外观的唯一来源。
图片2是原帧配准深度图，只锁定人体前后关系、动作几何、遮挡边界和可辨认褶皱起伏，不提供身份、产品、材质、颜色或场景外观。
【默认保留】任何没有绑定资产的对应格子都完整保留图片1内容；不得擅自替换、删除、美化或重绘。
【槽位规则】模特A只对应人物A，产品A只对应产品A；B、C及后续槽位依次类推。不得合并、互换、串穿或混搭。
【输出规则】只输出一张完成的连续分镜画面，不输出拼图、对照图、参考图、深度图、界面或说明文字。
```
