# 导演远程 Web 部署与使用说明

## 当前可用范围

版本 `1.0.0.244` 已内置导演远程工作台。安装后无需另行部署前端，桌面软件会在开启远程访问时同时提供 Web 页面和 `/api/v1` 接口。

首版已支持：

- 查看桌面端当前打开的工程与统计信息。
- 查看故事板列表、分组、画面、翻转状态、说明和摘要。
- 使用导演权限对整张故事板或单个分镜添加批注，并更新批注内容或解决状态。
- 使用导演权限编辑故事板名称、整体摘要、分镜说明和行说明；锁定的故事板只允许审阅与批注。
- 查看拍摄脚本列表、版本和全部镜头。
- 查看允许远程访问的镜头图片。
- 使用导演权限编辑镜头时长、画面、景别、运镜、构图、对白、声音、提示词等字段。
- 使用只读权限审阅内容但禁止保存。
- 桌面端与 Web 端通过 WebSocket 同步故事板和拍摄脚本变化。
- 多端同时修改时使用资源版本检查；冲突不会静默覆盖，而会加载服务器最新内容。

尚未 Web 化：视频导入与解析、故事板媒体导入/替换、自由布局与结构调整、桌面端批注管理面板、复刻工作流、视频生成任务、导出和软件设置。这些能力仍在桌面端使用，不能将当前版本描述为全功能等价版。

## 桌面端开启步骤

1. 安装并启动 `filmstoryboard 1.0.0.244`。
2. 打开要协作的工程，并保持桌面软件运行。
3. 进入“设置 → 导演远程访问”。
4. 展开卡片并开启“远程工作台”。默认地址为 `http://127.0.0.1:47836`。
5. 根据用途生成“导演配对码”或“只读配对码”。配对码为 6 位、10 分钟有效、成功使用一次后立即失效。

## 内网穿透要求

将穿透服务的本地上游指向设置页显示的完整地址，例如：

```text
http://127.0.0.1:47836
```

公网侧必须满足：

- 使用独立的 HTTPS 地址，不要直接把未加密 HTTP 暴露到公网。
- 页面、REST API 与 WebSocket 使用同一个公网域名并转发到同一个本地端口。
- 反向代理保留 WebSocket Upgrade，并传递 `X-Forwarded-Proto: https`。
- 不要把监听地址改成 `0.0.0.0`；当前服务刻意只监听回环地址，由本机穿透客户端连接。
- 公网地址由穿透服务提供，不需要填写到软件内；浏览器打开该公网地址即可进入配对页。

## 权限与安全

- 远程功能默认关闭；关闭后端口停止监听，当前会话和配对码全部撤销。
- 访问令牌仅以 SHA-256 摘要保存在内存；软件重启后所有远程会话失效。
- 浏览器使用 `HttpOnly + SameSite=Strict` Cookie，脚本无法读取会话令牌。
- WebSocket 使用 30 秒有效且只能消费一次的独立票据，不把长期令牌放入 URL。
- 每分钟连续 5 次错误配对会触发限流；最多保留 8 个活动会话。
- 媒体接口只接受不透明 ID，只允许当前工程目录内的白名单图片、音频和视频格式，不返回本机绝对路径。
- 审计日志写入软件 `data/logs/remote_access_audit.jsonl`，令牌、配对码和本机路径会脱敏。

## 故障排查

### 本机地址打不开

- 确认设置卡片显示“远程工作台运行中”。
- 检查端口是否被其他程序占用；可在设置页改用 1024–65535 范围内的其他端口。
- 如果提示 Web 页面资源未安装，请使用 `1.0.0.244` 的正式安装包重新安装。

### 公网能打开页面但无法登录或实时同步

- 确认穿透上游是设置页显示的本机地址，而不是磁盘中的 Web 文件目录。
- 确认 REST 与 WebSocket 没有被分流到不同域名。
- 确认代理支持 WebSocket Upgrade，并传递 HTTPS 协议信息。
- 重新生成配对码；旧码可能已被使用或超过 10 分钟。

### 看不到工程内容

- 桌面端必须先打开工程。
- 工作台会分别展示故事板和拍摄脚本；对应模块没有内容时，该模块列表为空。
- 故事板媒体必须仍在当前工程目录内且命中媒体白名单；无效或越界路径不会暴露给浏览器。

## 构建与安装资源

- Web 源码：`website/app`
- Web Release：`website/app/build/web`
- Web 优化脚本：`website/app/scripts/optimize_web_build.ps1`
- 桌面安装脚本：`installer/filmstoryboard.iss`
- 正式安装包：`dist/installer/filmstoryboard-Setup-1.0.0.244.exe`

安装器会将 Web Release 复制到 `{app}/web`；桌面控制器在正式安装环境优先读取该目录，开发环境才回退到仓库中的 `website/app/build/web`。
